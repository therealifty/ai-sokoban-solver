# ai-sokoban-solver
AI-based Sokoban puzzle solver using search algorithms to find optimal solutions in a grid-based environment.
## 🤖 AI Project: Sokoban Solver

This project is an AI-based implementation of the classic Sokoban game solver. It uses search algorithms to find optimal or near-optimal solutions for pushing boxes to target locations.

## 📦 Project Files
- sokoban.zip → Contains full source code and implementation

## ⚙️ How to Run
1. Download `sokoban.zip`
2. Extract the file
3. Open project in your preferred IDE or terminal
4. Run the main file according to instructions inside the code
